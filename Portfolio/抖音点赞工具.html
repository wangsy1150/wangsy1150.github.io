PROJECT 13 · 自动化

抖音点赞工具

基于浏览器自动化的抖音批量互动脚本：按目标账号进入作品页，模拟真人节奏完成点赞、收藏等操作，支持批量执行与数量控制。

Python DrissionPage XPath 自动化控制

项目背景

这是一个把「重复手工操作」交给程序的项目。难点不在点击本身，而在如何让自动化不被识别、不误触、不中断： 抖音的按钮是动态渲染的，滚动加载会改变元素位置，操作节奏太快会触发风控。

技术要点

浏览器接管

用 DrissionPage 直接接管已登录的 Chrome 实例，复用真实登录态，避免反复扫码。

元素定位

用 XPath 按文案与属性双重条件定位点赞 / 收藏按钮，比固定选择器更抗页面改版。

节奏控制

每次操作间插入随机延时，模拟自然停顿，降低被判定为机器的概率。

批量与计数

支持传入目标列表与执行上限，跑完自动停止，避免无边界循环。

执行流程

  • 启动浏览器 — 接管本地已登录会话，打开目标作品页。
  • 等待渲染 — 显式等待目标元素出现，而非固定 sleep，兼顾速度与稳定。
  • 判断状态 — 读取按钮当前是否已点赞，已操作过的直接跳过，避免重复计数。
  • 执行操作 — 点击目标按钮，随机延时后进入下一个目标。
  • 循环终止 — 达到设定数量或目标列表耗尽即结束，输出执行摘要。

关键代码结构

from DrissionPage import ChromiumPage import random, time page = ChromiumPage() # 接管已登录的浏览器 for url in targets: page.get(url) page.wait.ele_displayed('xpath://div[contains(@class,"like")]') btn = page.ele('xpath://div[@data-e2e="like-icon"]') if not is_liked(btn): # 已操作过则跳过 btn.click() time.sleep(random.uniform(1.5, 3.2)) # 随机节奏
说明：这是一个自动化效率工具的练习项目，用于验证浏览器自动化在动态页面上的稳定性。 实际使用需遵守平台规则，仅用于自己账号的日常互动管理。
