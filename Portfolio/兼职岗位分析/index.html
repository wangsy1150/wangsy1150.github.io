三条边界（写到结论旁边，而不是藏起来）

①

数据是模拟的，不是招聘平台的真实报价

CSV 自身带 数据性质 和 薪资口径说明 两个字段，明写「模拟演示数据 / 非真实招聘报价」。 我在页面上把这个声明放在结论之前，而不是放到最后一行小字里 —— 因为一旦读者以为这是真实行情， 后面所有精确到小数点的溢价率都会变成误导。

②

6.6 倍这个数，取决于拿谁做分母

「复合岗时薪是基础服务的 6.6 倍」听起来很响，但它只是两个极端组之差。 真正有解释力的是同一句里的另一半：复合岗比单技能最强的 AIGC 还高 50% —— 那个才是「复合」本身的价值， 因为它的对照物里已经排掉了「数字类岗位本来就比体力岗贵」这个因素。

③

相关不等于因果

数据能说明「带这两个技能的岗位，标的薪资更高」，不能说明「学了这两样就一定能拿到那个数」。 薪资是岗位定价，不是个人能力价格 —— 中间还隔着经验、城市、公司、谈判。这条我没法用数据证明，所以只能明写。

分析口径与流程

  • 先定分组 — 数据集里 技能方向 这个字段天然给了分组依据： 基础服务 / 普通数字岗位 / Python / AIGC / Python+AIGC。不自己造标签，用数据自带的。
  • 再定指标 — 每组取 时薪_元、参考日薪_元、预计月收入_元 的均值， 外加 每周工时、远程办公 占比、成长潜力_1至5、技能门槛_1至5、岗位热度指数。
  • 算溢价 — 溢价率 = (复合 − 对照) / 对照 × 100。 时薪 和 月薪 的溢价率不同（564.2% vs 401.2%），因为基础岗周均工时更长（22.1h vs 16.6h）。
  • 算趋势 — 按 年月 分组求月薪均值，18 个点做一元线性拟合取斜率，单位换算成「元/季」便于阅读。
  • 交叉验证 — 同一结论用三种图说：KPI 给数值、柱状给绝对量、雷达给结构。三张图说的不是同一件事才算验证。

关键代码

# 分组聚合 + 溢价率（真实写法，就是生成上面那些数字的代码） df = pd.read_csv(CSV, encoding='utf-8-sig') comp = df[df['技能方向'] == 'Python+AIGC'] # 复合型组 5,032 条 base = df[df['技能方向'] == '基础服务'] # 基础对照组 9,253 条 comp_month = round(comp['预计月收入_元'].mean(), 1) # 14081.1 base_month = round(base['预计月收入_元'].mean(), 1) # 2809.3 premium_rate = round((comp_month - base_month) / base_month * 100, 1) # 401.2

整个页面的结论支点就是这三个数；其余图表都是围绕它们做交叉验证。

# 趋势斜率：18 个月线性拟合，单位换成「元/季」 p = df.pivot_table(index='年月', columns='技能方向', values='预计月收入_元', aggfunc='mean') x = np.arange(len(p)) for col in p.columns: k, b = np.polyfit(x, p[col].values, 1) print(col, f'每季度 {k*3:.1f} 元') # 复合型 +503.7 / 基础服务 +7.2

斜率用的是全 18 个点的最小二乘拟合，不是「末月减首月」——后者对端点噪声太敏感。

可视化是论证不是装饰

每张图都要能回答一个具体问题。KPI 给数值、柱状给绝对量、雷达给结构、折线给趋势 —— 四张图说四件事，而不是把同一个数画四遍。
