这个分数是怎么来的

input 输入

两个名字是 Python 用 input 收进去存成变量的，页面只负责把 boy_name / girl_name 读出来显示。

random.randint

yf 这个分是 random.randint(1, 100) 摇出来的，页面不重摇、也不改数，刷新看到的永远是同一个。

if / elif / else

按 yf 落在哪一档进不同分支，分数越高进的档越暖，话术和底色一起换。

分支结果

分支选中的那套话术直接显示出来，所以同一份名单，分数不同结果就完全不同。
