波奇酱桌面宠物

一只常驻 Windows 桌面的小挂件：无边框、置顶、色键透明。 她会饿、会生气、会被摸头，也会在你久不理她的时候主动开口。用 Python + Tkinter 单进程实现 —— 不依赖浏览器，也不依赖 Electron，常驻内存约 30 MB。

项目背景

在桌面上放一只猫，常见做法是 Electron —— 为了一个挂件塞进一整个浏览器内核。这个项目走了另一条路： 用 Python 标准库自带的 tkinter，单进程常驻。代价是两件麻烦事得自己扛： 系统不支持逐像素透明（只能色键抠图），以及无边框窗口的 尺寸、位置、点击区域全部要手算。3.0 版把这两件事都处理干净了。

三种状态，三张素材

正常饱食度 > 30
饿了≤ 30
生气== 0

源素材的背景是纯品红 #FF00FF，图片里并没有 alpha 通道 —— 屏幕上看到「透明」，是因为程序把这个颜色声明成了透明的结果。 上面那个场景里用的就是这三张图，把品红抠成透明之后贴到桌面上。

技术要点

色键透明，不是 alpha

tkinter 只认精确颜色。做法是素材背景刷品红、窗口底色也设成品红、再把它声明为 transparentcolor。差一个色号就会露边。

窗口紧贴角色本体

2.0 的窗口固定 220×172，而角色只占 55×132 —— 那圈「看不见」的透明区域仍然吃掉鼠标点击、挡住桌面图标。3.0 改成按角色实际宽高反推窗口尺寸。

一个常量控全局

想调大小只改 PET_TARGET_H（当前 232，2.0 是 132），窗口尺寸、坐标、边距全部跟着算，不用手改一堆常量。

为什么要清两次边

缩放会把品红和角色边缘混成脏边。在原始尺寸清只需 3px 半径；留到放大 1.8 倍后再清，就得用 16px —— 而那个半径会误伤角色内部的粉色。

放大用 BICUBIC

LANCZOS 的核有负旁瓣，放大时会在强边缘产生明显振铃。这里是放大不是缩小，所以用 BICUBIC。

贴边吸附 + 多屏

拖到屏幕边缘会停靠过去；拖到副屏之后，不会再被「随机走动」按主屏边界拽回主屏。

从一张素材到桌面上的一只猫

  • 读素材 — 打开状态图，先清一遍轮廓外的色键污染（半径 3px）。
  • 裁到角色本体 — 不再贴进固定方框，角色有多宽图就有多宽。
  • 等比放大 — 缩放到 PET_TARGET_H（232px 高），宽度按原比例算，绝不拉伸变形。
  • 再去一次绿边 — 处理放大新产生的过渡带，这时候半径小也很轻松。
  • 围一圈品红边 — 保证轮廓外有背景色可清，再整体清一次。
  • 反推窗口尺寸 — 按成品图片宽高算窗口大小，创建无边框置顶窗口，底色同样设为品红。
  • 主循环 — 饱食度每 5 秒 -5；每 1.5 秒随机走一小步；每 30 分钟提醒喝水休息。

关键代码结构

# pet.py —— 色键与尺寸：想整体调大小，只改 PET_TARGET_H 就够了 KEY_COLOR = "#FF00FF" # 色键：图片背景和窗口底色都用它 # ---------- 尺寸：想整体调大小，只改 PET_TARGET_H 就够了 ---------- PET_TARGET_H = 232 # ★ 角色在屏幕上的高度（像素）。2.0 是 132 PET_MARGIN = 5 # 角色四周留的品红边距（也保证轮廓外有背景可以清边）
# pet.py —— create_bubble_window()：无边框 + 置顶 + 品红色键透明 win = tk.Toplevel(parent) win.overrideredirect(True) # 去掉标题栏与边框 win.attributes("-topmost", True) # 永远在最前面 win.configure(bg=KEY_COLOR) # 底色 = 品红，和素材背景完全一致 try: win.attributes("-transparentcolor", KEY_COLOR) # 声明品红为透明色 except tk.TclError: pass

透明不是「图片带透明通道」，而是「这个颜色不画」。所以 Label / Canvas 的 bg 必须和 KEY_COLOR 完全一致。
