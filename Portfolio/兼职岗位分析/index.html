⚠️
数据口径先说明：本项目使用的 兼职岗位数据.csv 是课程/练习提供的模拟演示数据集， 不是我从招聘平台采集的真实报价。数据集自带字段已明确标注「数据性质＝模拟演示数据」 「按技能稀缺度、城市和时间趋势生成，非真实招聘报价」。 因此这个项目展示的是分析口径与可视化链路，页面上所有结论仅在该模拟数据集上成立，不代表真实市场水平。 —— 我选择主动讲清这一点，因为分析的严谨性比结论好看更重要。

项目背景

手上拿到一份 3 万行的兼职岗位数据，里面有个字段叫「技能方向」。于是想回答一个很具体的问题： 同时会 Python 和 AIGC 的岗位，比纯基础服务岗到底值钱多少、值钱在哪。 「更值钱」只靠感觉说不清楚，也没法拿给别人看 —— 得先把感觉变成数字，再让数字能被追问。

运行截图

核心三个视角交叉验证同一个结论

顶部六个 KPI 给结论（月薪 14,081 元 vs 2,809 元、溢价率 401.2%、增长斜率 503.6 元/季、热度 91.6、成长潜力 4.51/5、远程办公率 77.1%）； 左侧柱状图给薪资差距的绝对量；右侧雷达图给结构——复合型在成长潜力、技能门槛、岗位热度、远程办公率四个维度全面外扩， 基础岗只在「培训可胜任率」「高考生适配率」上满格。一张图只能说一个数，三个视角才能说清结构。

扩展把结论拆到 13 个维度去验证

基础版回答「差多少」，扩展版回答「为什么差」。13 张图覆盖薪资五方向对比、成长潜力五维雷达、 技能方向结构环形、18 个月薪资趋势、岗位量与时薪双轴、热度仪表盘 —— 其中薪资趋势那条线最能说明问题：18 个月里复合型月薪从 12,786 涨到 15,406（+20.5%）， 基础岗从 2,768 到 2,801，几乎是一条平线。

技术要点

图表要做交叉验证

KPI 条给结论、柱状图给绝对量、雷达图给结构 —— 三个视角互相印证，而不是三张同义图。

聚合全在 Python 端

时薪/日薪/月收入均值、溢价率、成长潜力均值、远程办公率都由 pandas 算完再注入，前端只负责画。

占位符而非 f-string

HTML 模板里写 __COMP_MONTH__ 这类占位符最后统一替换 —— 直接拼 f-string 会被 CSS/JS 的花括号冲垮。

中文不被转义

注入 JS 时用 json.dumps(..., ensure_ascii=False)，否则中文全变成 \uXXXX。

让它"活"起来

KPI 数字用缓动函数做滚动动画、雷达图做呼吸效果、柱状图轮播高亮 —— 这些细节决定「专业还是不专业」。

主动标注数据边界

数据集自身的口径字段被原样写进页面顶部，而不是把模拟数据当市场事实陈述。

生成流程

  • 读数据 — pandas 读入 30,000 行 CSV，按 技能方向 字段切出复合型与基础服务两组。
  • 算指标 — 分组求均值：时薪、参考日薪、预计月收入、成长潜力、技能门槛、热度指数、远程办公率。
  • 算趋势 — 按季度聚合月薪均值，用线性拟合求出 18 个月的增长斜率。
  • 注入模板 — 指标转 JSON 塞进 HTML 模板的占位符，中文用 ensure_ascii=False 保持可读。
  • 渲染图表 — ECharts 画柱状图与雷达图，另加缓动数字动画与呼吸效果。

关键代码结构

# 生成可视化大屏.py —— 分组聚合（节选，真实写法） df = pd.read_csv(CSV, encoding='utf-8-sig') comp = df[df['技能方向'] == 'Python+AIGC'] # 复合型组 base = df[df['技能方向'] == '基础服务'] # 基础对照组 comp_month = round(comp['预计月收入_元'].mean(), 1) # 14081.1 base_month = round(base['预计月收入_元'].mean(), 1) # 2809.3 premium_rate = round((comp_month - base_month) / base_month * 100, 1) # 401.2%

三个数字就是整个页面的结论支点 —— 其余图表都是围绕它们做交叉验证。

# 雷达图六维：复合型 vs 基础服务（0-100 归一化） compRadar = [90.3, 90.0, 91.6, 77.1, 88.6, 17.9] # 成长/门槛/热度/远程/可胜任/高考适配 baseRadar = [40.1, 29.9, 62.8, 0.0, 100.0, 100.0] # 这张图真正想说的：基础岗在"可胜任率/高考适配率"上满格， # 在成长潜力与技能门槛上被压到底 —— 低门槛、人人可入、但天花板封顶。

雷达图的"结构性分化"比任何单个数字都更能解释「值钱在哪」。
