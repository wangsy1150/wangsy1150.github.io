项目背景

二手房价格数据是典型的「高价值但难拿」：页面结构会调整、列表页有滚动懒加载、翻页过程中还会按频次触发人机验证。 更要紧的是这个需求背后有一个具体的人——他要的不只是一堆字段，还要求图片能直接在表格里看到。 所以这个项目的目标不是「脚本能跑一次」，而是把「滚到底 → 过验证 → 取字段 → 存表 → 插图」这条链路做稳， 并且交付物的格式要能让对方一眼验收。

技术要点

「滚到底」不靠猜次数

没用固定的 range(50)，而是每次滚 500px 后比较滚动前后的纵向位置，位置不再变化才 break。 网络慢的时候也不会漏数据。

相对路径而非绝对路径

每个字段都从当前那条房源 li 用 .// 往下找。 用整页绝对路径的话，第二条的标题会串到第一条上。

验证码按类型分流

单一滑块方案应付不了所有情况：图形点选类走「按图片顺序点击」的解法，滑块类走拖拽轨迹， 封装成独立 tools 模块，主流程只负责调用与重试。

图片真的"进到"表格里

只把图片链接写进单元格不算交付。单独一步下载图片并插入对应单元格， 同时调列宽与行高，否则图片会盖住相邻格子。

交付流程本身就是设计

动工前先问清四件事：要多少条、要不要图片、页面结构复不复杂、有没有反爬。 先发一份样例截图 + 列名让对方确认格式，确认后才出全量——避免返工成本全落在自己身上。

做完显式关闭浏览器

采集结束调 page.quit()。不关的话进程会一直挂着，白占资源。

执行流程

  • 打开列表页 — DrissionPage 启动浏览器，按页码循环访问 /ershoufang/pg{i}/。
  • 验证码分流 — 每一页进正文前先过一次 crack_captcha(page)，按验证类型选择解法。
  • 滚动加载 — 每次下滚 500px 并留 0.3s 给图片加载，直到纵向位置不再变化。
  • 相对路径取字段 — 定位 ul.sellListContent 下所有房源 li，逐条用相对路径取 8 个字段。
  • 落表并插图 — pandas.DataFrame 一次性写出 Excel，再调 add_images_to_excel 把图片列嵌入表格。

关键代码结构

# 贝壳二手房数据获取.py —— 滚动到底判断 + 相对路径取字段（真实写法） from DrissionPage import ChromiumPage import pandas from tools.add_image import add_images_to_excel from tools.captcha_solver import crack_captcha page = ChromiumPage() for i in range(1, 8): # 共 7 页 page.get(f'https://bj.ke.com/ershoufang/pg{i}/') crack_captcha(page) # 人机验证按类型分流 page.wait(2) # 滚到底：比较滚动前后的纵向位置，位置不变才说明到底 for _ in range(30): height = page.rect.scroll_position[1] page.scroll.down(500) time.sleep(0.3) # 给图片留加载时间 if height == page.rect.scroll_position[1]: break lis = page.eles('xpath://ul[@class="sellListContent"]/li[@class="clear"]') for li in lis: info = { "标题": li.ele('xpath:.//div[@class="title"]/a').text, "总价": li.ele('xpath:.//div[@class="totalPrice totalPrice2"]/span').text, "图片网址": li.ele('xpath:.//img[@class="lj-lazy"]').attr('src'), # ... 共 8 个字段 } all_data.append(info) page.quit() df = pandas.DataFrame(all_data) df.to_excel('终版交付.xlsx', index=False) add_images_to_excel('终版交付.xlsx', df['图片网址'], 'H')

两个点值得看：if height == page.rect.scroll_position[1]: break 是「滚到底」的判据； 字段全部从 li 用 .// 相对定位，这是不串行的关键。

踩过的坑

滚太快会抓到空图

懒加载图片没载完就取 src，拿到的可能是占位图。留出加载时间比事后补数据划算。

只存链接不算交付

把图片链接写进单元格，对方还要自己一张张点开——这不叫交付。图片要真的嵌进表里。

先确认格式再出全量

样例和列名发过去确认，比做完再返工省事得多。这一步是流程设计，不只是技术。

这个项目教了我什么

稳定 > 跑通

「能跑一次」和「能重复跑」是两件事。滚动判断、验证码分流、显式关浏览器，都是在补稳定性。

交付物是设计出来的

需求阶段问清四件事、样例先过审、文件名直接叫「终版交付」—— 对方打开就能验收，这才叫完成。
