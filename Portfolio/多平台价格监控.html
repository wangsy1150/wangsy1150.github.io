多平台价格监控

跨商城商品价格监控系统：定时采集京东、淘宝等平台的目标商品价格，命中预设阈值时通过微信推送提醒，并支持定时任务自动收尾。

Python DrissionPage APScheduler Server酱推送 JSON 持久化

项目背景

「等到降价再买」这件事最适合交给程序。这个项目把定时抓取 → 价格比对 → 命中提醒 → 任务收尾 串成一条完整链路，并且针对每个平台单独处理了登录态与页面差异，而不是用一份代码硬套所有站点。

技术要点

多平台适配

京东、淘宝各写独立采集器，共用同一套「读取目标 → 抓价 → 比对 → 推送」的主流程。

定时调度

APScheduler 管理定时任务，按设定间隔自动执行，无需人工触发。

微信推送

接入 Server酱，把「某商品已降到目标价」推到微信，SendKey 由环境变量注入。

任务自收尾

监控任务由独立脚本启动，达到条件后自动结束并清理，避免进程长期驻留。

执行流程

  • 加载目标 — 读取待监控商品列表：名称、链接、目标价格。
  • 逐项抓价 — 按平台分发到对应采集器，取回当前价格与库存状态。
  • 比对阈值 — 当前价 ≤ 目标价时进入提醒分支，否则只记录不打扰。
  • 推送通知 — 通过 Server酱把商品名、原价、现价、链接推到微信。
  • 任务收尾 — 独立调度脚本负责启动与结束，全程无人值守。
